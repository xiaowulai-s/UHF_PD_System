## 1. 概述

### 1.1 技术路线

本系统采用 **基于 PRPD（Phase Resolved Partial Discharge）统计特征的规则-评分混合分类策略**，核心思路为：

1. 将所有放电事件按相位角映射到 **6 个扇区**，计算各扇区的能量分布
2. 从扇区分布中提取 **多维统计特征**（对称性、集中度、扩散度等）
3. 通过 **四条并行规则** 分别对每种放电类型打分
4. 根据强匹配/弱匹配两种路径决策最终类型，并给出置信度

### 1.2 分类目标

| 类型标识 | 中文名称 | 英文名称 |
|----------|----------|----------|
| `internal` | 内部气隙放电 | Internal Discharge |
| `corona` | 电晕放电 | Corona Discharge |
| `surface` | 沿面放电 | Surface Discharge |
| `floating` | 悬浮颗粒放电 | Floating Discharge |

### 1.3 实现位置

- **主分类器**：`ui/pages/analysis_page.py` → `DischargeClassifier` 类
- **离线分析工具**：`tools/prpd_analyzer.py` → `_classify_discharge_type()` 函数（简化版）

## 2. 扇区划分体系

### 2.1 六扇区定义

将一个完整工频周期（0° ~ 360°）均分为 6 个 60° 扇区：

```
        90°
         │
   S2    │    S1
(60~120)│ (0~60)     ← 正半周
         │
 180°────┼──── 0° / 360°
         │
   S3    │    S6
(120~180)│(300~360)    ← 负半周
         │
        270°
   S4 (180~240)   S5 (240~300)
```

| 扇区编号 | 相位范围 | 半周归属 | 物理含义 |
|:--------:|:--------:|:--------:|:---------|
| S1 | 0° ~ 60° | 正半周 | 正向过零点附近上升沿 |
| S2 | 60° ~ 120° | 正半周 | 正向峰值区域前段 |
| S3 | 120° ~ 180° | 正半周 | 正向峰值区域后段至过零 |
| S4 | 180° ~ 240° | 负半周 | 负向过零点附近下降沿 |
| S5 | 240° ~ 300° | 负半周 | 负向峰值区域前段 |
| S6 | 300° ~ 360° | 负半周 | 负向峰值区域后段至过零 |

### 2.2 双通道加权计算

每个扇区同时计算两种权重：

| 权重类型 | 计算方式 | 用途 |
|----------|----------|------|
| **计权（Count）** | 扇区内事件数 / 总事件数 | 主判断依据 |
| **幅值加权（Weighted）** | 扇区内 Σ(幅值) / 总 Σ(幅值) | 辅助验证，抑制低幅值噪声影响 |

数学表达：

$$
\text{sec}_i^{\text{count}} = \frac{\sum \mathbb{1}(\phi_i \leq \phi < \phi_{i+1})}{N_{\text{total}}}
$$

$$
\text{sec}_i^{\text{weighted}} = \frac{\sum_{\phi_i \leq \phi < \phi_{i+1}} A(\phi)}{\sum_{\text{all}} A(\phi)}
$$

其中 $\phi$ 为相位角，$A(\phi)$ 为对应事件的幅值。

## 3. 数据预处理

### 3.1 最小数据量门槛

当有效事件数 `< 10` 时，直接返回「未知」类型，不进行分类：

```python
if len(phases) < 10:
    return {"type": "unknown", "confidence": 0, ...}
```

### 3.2 自适应去噪

采用动态阈值过滤低幅值噪声事件：

**阈值计算公式：**

$$
T_{\text{noise}} = \max\left( M_{\text{amp}} \times 2.0,\; P_5 \times 1.5,\; T_{\text{min}} \right)
$$

其中：
- $M_{\text{amp}}$ = 幅值中位数
- $P_5$ = 幅值第 5 百分位数
- $T_{\text{min}}$ = 最小阈值（取非零最小值或 1.0）

**保留策略**：若过滤后剩余事件数不足原始的 30%（且不少于 20 个），则放弃过滤，使用全部数据。

```
输入 N 个事件
    ↓
计算 noise_threshold
    ↓
过滤 → 剩余 n_clean 个
    ↓
n_clean ≥ max(20, N×30%)?
    ├─ YES → 使用过滤后数据 ✓
    └─ NO  → 回退到全部数据（不过滤）
```

---

### 3.3 纯噪声场景拒绝

当输入信号为纯随机噪声时，分类器仍会强制归为四种类型之一（通常匹配到悬浮颗粒放电，因为 spread 高、top2 低），造成误报。

**判定逻辑**：在进入四类评分前，先执行噪声拒判检查：

```python
if spread > 0.80 and max_amp < noise_floor * 2:
    return {"type": "noise", "confidence": min(spread, 0.90), ...}
```

其中：
- `spread > 0.80` — 全相位均匀分散，无集中扇区
- `max_amp < noise_floor * 2` — 最大幅值接近噪声底限
- `noise_floor` = 自适应去噪阈值（见 3.2 节）或传感器本底噪声

> **注**：实际使用中可根据现场噪声水平调整 `spread` 阈值（推荐范围 0.75~0.85）。

## 4. 特征提取

从 6 扇区分布中提取以下 **13 维特征指标**：

### 4.1 核心特征

| # | 特征名 | 公式 | 取值范围 | 含义 |
|---|--------|------|:--------:|------|
| 1 | **quad13** | S1 + S4 | 0 ~ 1 | 第一+三象限集中度。内部气隙的核心指标，值越高越偏向内部气隙 |
| 2 | **symmetry** | 1 - \|S1 - S4\| / max(S1, S4) | 0 ~ 1 | S1 与 S4 的对称度。1=完全对称，0=完全不对称 |
| 3 | **spread** | S2 + S3 + S5 + S6 | 0 ~ 1 | 签名区外扩散程度。值越大表示分布越分散（悬浮颗粒特征）|
| 4 | **top2** | 排序后最高两扇区占比之和 | 0.33 ~ 1 | 集中度。值越小表示能量越分散（悬浮颗粒特征）|
| 5 | **pos_ratio** | S1 + S2 + S3 | 0 ~ 1 | 正半周占比。用于区分正半周主导型（沿面）和负半周主导型（电晕）|

### 4.2 辅助特征

| # | 特征名 | 公式 | 取值范围 | 含义 |
|---|--------|------|:--------:|------|
| 6 | **s1_ratio** | S1 / (S1 + S4) | 0 ~ 1 | S1 在 quad13 中的占比。>0.65 强烈暗示沿面放电 |
| 7 | **asymmetry_ratio** | \|W_pos - W_neg\| / (W_pos + W_neg) | 0 ~ 1 | 正负半周幅值加权能量不对称度。0=对称，1=完全不对称 |
| 8 | **s1_dominance** ⚠️ | S1 / (S1+S2+S3) | 0 ~ 1 | S1 在正半周内的主导程度。当前已计算但评分规则未使用，建议加入沿面放电评分因子 |
| 9 | **neg_tail_count** | S5 + S6 | 0 ~ 1 | 负尾部（240°~360°）计权占比 |
| 10 | **neg_tail_weight** | W5 + W6 | 0 ~ 1 | 负尾部幅值加权占比 |
| 11 | **max_amp** | max(amplitudes) | >0 | 最大幅值（mV），用于严重等级判定 |

### 4.3 新增特征（建议）

以下特征当前未在 `DischargeClassifier` 中实现，但有助于提升边界案例的区分能力：

| # | 特征名 | 公式 | 取值范围 | 含义 | 适用场景 |
|---|--------|------|:--------:|------|----------|
| 12 | **corona_tail** | S6 / (S5 + S6 + 1e-10) | 0 ~ 1 | S6 在负尾部中的主导程度。接近 1 表示放电集中在 300°~360°（电晕特征） | 强化电晕判据 |
| 13 | **s1_forward** | S1 / (S1+S2+S3) | 0 ~ 1 | S1 在正半周中的前沿占比（同 s1_dominance），>0.6 强烈暗示沿面放电前沿集中 | 沿面放电评分 |
| 14 | **amp_skewness** | $\frac{\frac{1}{n}\sum (A_i - \bar{A})^3}{\sigma_A^3}$ | — | 幅值分布偏度。偏度 >> 0 表示高幅值尾部厚（内部气隙）；偏度 ≈ 0 表示对称（悬浮颗粒）；偏度 << 0 表示低幅值集中（电晕） | 辅助区分 |
| 15 | **amp_kurtosis** | $\frac{\frac{1}{n}\sum (A_i - \bar{A})^4}{\sigma_A^4} - 3$ | — | 幅值分布峰度（超值峰度）。高值表示幅值集中在特定区间（电晕）；低值表示幅值分散（悬浮颗粒） | 辅助区分 |

### 4.3 特征关系图

```
                    pos_ratio 高 (>0.55)
                    正半周占优
                         │
            ┌────────────┼────────────┐
            │            │            │
      s1_ratio 高      对称          不对称
      (>0.65)       symmetry 高    asymmetry 高
            │       (>0.60)        (>0.20)
            │            │            │

      │           │     │       │         │

      │                              │

      │                              │
      ▼                              ▼

## 5. 四种放电类型指纹

### 5.1 内部气隙放电 (Internal Discharge)

**物理机理**：绝缘介质内部气隙、气泡或杂质在交变电场下发生局部击穿。

**PRPD 图谱特征**：
- 正负半周 **近似对称**
- 放电集中出现在 **电压过零点附近**的上升/下降沿
- 即 **S1（0°~60°）和 S4（180°~240°）** 占绝对主导
- 幅值范围较宽，但相位集中度高

**判断标准**：

| 条件类型 | 阈值 | 说明 |
|----------|------|------|
| **强匹配** | `quad13 > 0.50` 且 `symmetry > 0.60` 且 `spread < 0.55` | 三条件同时满足 |
| **评分公式** | `quad13 × 0.5 + symmetry × 0.3 + (1 - spread/0.55)^+ × 0.2` | 加权综合分 |

其中 $(x)^+ = \max(0, x)$。

**典型扇区分布示意**：

```
幅值 ↑
     │  ████                ████
     │  ████                ████
     │  ██                  ██
     │  █                   █
     │
     └──────────────────────────→ 相位
        S1██████        S4██████
        (0~60°)         (180~240°)
```

---

### 5.2 电晕放电 (Corona Discharge)

**物理机理**：高压导体表面电场不均匀（尖端、毛刺等）导致空气电离。

**PRPD 图谱特征**：
- **高度不对称**，几乎只出现在 **负半周**
- 集中在 **S6（300°~360°）** 区间，即负向峰值后的下降沿
- 正半周放电极少或完全没有
- 幅值相对稳定，离散度小（峰度高）
- `corona_tail = S6 / (S5+S6)` 接近 1.0（放电集中在 S6 而非 S5）

**判断标准**：

| 条件类型 | 阈值 | 说明 |
|----------|------|------|
| **强匹配** | `(neg_tail_weight > 0.60 或 neg_tail_count > 0.50)` 且 `pos_ratio < 0.25` | 负半周绝对主导 + 正半周受抑制 |
| **评分公式** | `evidence × 0.5 + pos_suppress × 0.3 + (weight_dom - 0.3)^+ × 0.2 + tail_bonus × 0.1` | 四因子加权 |

其中：
- `evidence` = `neg_tail_weight`（若 > 0.5）否则用 `neg_tail_count`
- `pos_suppress` = `max(0, 1 - pos_ratio × 4)` — 正半周越少得分越高
- `weight_dom` = `neg_tail_weight`
- `tail_bonus` = `max(0, corona_tail - 0.6) × 2` — 放电集中在 S6（300°~360°）的额外加分。`corona_tail ≈ 1` 时加分最大，≈0.5 时（S5/S6 均匀）无加分

> 电晕放电的幅值分布峰度高（幅值集中），可进一步与沿面放电区分。

---

### 5.3 沿面放电 (Surface Discharge)

**物理机理**：绝缘材料表面因污染、受潮等原因，沿面发生爬电。

**PRPD 图谱特征**：
- **正半周占优**（通常正半周占比 > 60%）
- **S1（0°~60°）** 主导正半周
- 正负半周 **明显不对称**
- 负半周可能存在少量放电但分布分散
- `s1_dominance > 0.6`（S1 在正半周中占主导，放电集中在上升沿）

**判断标准**：

| 条件类型 | 阈值 | 说明 |
|----------|------|------|
| **强匹配** | `s1_ratio > 0.65` 且 `asymmetry_ratio > 0.20` 且 `pos_ratio > 0.55` | S1主导 + 不对称 + 正半周占优 |
| **评分公式** | `pos_bias × 0.3 + s1_forward_bonus × 0.2 + asym_bonus × 0.25 + neg_suppress × 0.25` | 四因子加权 |

其中：
- `pos_bias` = `max(0, (s1_ratio - 0.5) × 2)` — S1 主导度
- `s1_forward_bonus` = `max(0, s1_dominance - 0.5) × 2` — 放电集中在正半周前沿（0°~60°）的额外加分。特征区分度高：沿面放电 > 0.6，内部气隙 ≈ 0.5
- `asym_bonus` = `asymmetry_ratio` — 不对称加分
- `neg_suppress` = `max(0, 1 - neg_tail_count × 3)` — 负半周越少越好

**典型扇区分布示意**：

```
幅值 ↑
     │  ██████
     │  ██████
     │  ████
     │  ██
     │  █              ██
     │                 █
     └──────────────────────────→ 相位
        S1████████████
        (0~60°)
```

---

### 5.4 悬浮颗粒放电 (Floating Discharge)

**物理机理**：设备内部金属异物（松动部件、金属碎屑等）处于悬浮电位，在电场作用下引发放电。

**PRPD 图谱特征**：
- **相位分布宽**，无明显集中区间
- 各扇区均有放电事件，**无单一主导扇区**
- 幅值通常较大且分散
- 正负半周大致均匀或轻度不对称

**判断标准**：

| 条件类型 | 阈值 | 说明 |
|----------|------|------|
| **强匹配** | `top2 < 0.50` 且 `quad13 < 0.55` | 低集中度 + 无象限聚集 |
| **评分公式** | `uniformity × 0.5 + (1 - quad13/0.6)^+ × 0.3 + (spread/0.6)^+ × 0.2` | 三因子加权 |

其中 `uniformity` = `max(0, 1 - (top2 - 0.35)/0.45)` — 均匀度。

**典型扇区分布示意**：

```
幅值 ↑
     │  ██        ██        ██        ██
     │  ██        ██        ██        ██
     │  █         █         █         █
     │
     └──────────────────────────────────→ 相位
        S1  S2      S3  S4     S5  S6
        （全扇区均有分布，无显著峰）
```

## 6. 规则引擎与评分机制

### 6.1 四条规则并行执行

系统对四种放电类型 **同时独立打分**，互不依赖：

```
                    ┌─────────────────┐
                    │   输入特征向量    │
                    └────────┬────────┘
                             │
           ┌─────────────────┼─────────────────┐
           │                 │                 │
           ▼                 ▼                 ▼
    ┌────────────┐  ┌────────────┐  ┌────────────┐  ┌────────────┐
    │ 电晕规则   │  │ 沿面规则   │  │ 内部规则   │  │ 悬浮规则   │
    │ corona_match│  │ surface_   │  │ internal_  │  │ floating_  │
    │ corona_strong│ │ match      │  │ match      │  │ match      │
    └─────┬──────┘  └─────┬──────┘  └─────┬──────┘  └─────┬──────┘
          │               │               │               │
          ▼               ▼               ▼               ▼
    (score, strong) (score, strong) (score, strong) (score, strong)
           │                 │                 │               │
           └─────────────────┴─────────────────┴───────────────┘
                             │
                             ▼
                       决策模块（见第7节）
```

### 6.2 各规则评分明细

#### 规则 1：电晕放电 (corona)

| 因子 | 权重 | 计算方式 | 物理意义 |
|------|:----:|----------|----------|
| evidence | 45% | `neg_tail_weight`(>0.5时) 或 `neg_tail_count` | 负尾部主导证据强度 |
| pos_suppress | 25% | `max(0, 1 - pos_ratio × 4)` | 正半周抑制程度 |
| weight_bonus | 20% | `max(0, neg_tail_weight - 0.3)` | 幅值加权额外奖励 |
| tail_bonus | 10% | `max(0, corona_tail - 0.6) × 2` | S6/(S5+S6) 集中加分。`corona_tail≈1` 时加分最大 |

#### 规则 2：沿面放电 (surface)

| 因子 | 权重 | 计算方式 | 物理意义 |
|------|:----:|----------|----------|
| pos_bias | 30% | `max(0, (s1_ratio - 0.5) × 2)` | S1 在正半周的主导程度 |
| s1_forward_bonus | 20% | `max(0, s1_dominance - 0.5) × 2` | S1 在正半周中的前沿占比加分 |
| asym_bonus | 25% | `asymmetry_ratio` | 正负不对称程度 |
| neg_suppress | 25% | `max(0, 1 - neg_tail_count × 3)` | 负半周稀疏程度 |

#### 规则 3：内部气隙放电 (internal)

| 因子 | 权重 | 计算方式 | 物理意义 |
|------|:----:|----------|----------|
| quad13 | 50% | `S1 + S4` | 第一+三象限集中度 |
| symmetry | 30% | `1 - \|S1-S4\|/max(S1,S4)` | S1↔S4 对称性 |
| low_spread | 20% | `max(0, 1 - spread/0.55)` | 低扩散奖励 |

#### 规则 4：悬浮颗粒放电 (floating)

| 因子 | 权重 | 计算方式 | 物理意义 |
|------|:----:|----------|----------|
| uniformity | 50% | `max(0, 1 - (top2-0.35)/0.45)` | 分布均匀程度 |
| low_quad13 | 30% | `max(0, 1 - quad13/0.6)` | 无象限聚集 |
| high_spread | 20% | `max(0, spread/0.6)` | 高扩散奖励 |

## 7. 决策流程

### 7.1 两级决策机制

```
                    ┌──────────────────────┐
                    │  4条规则的 score & strong 标志  │
                    └──────────┬───────────┘
                               │
                    存在 strong=True 的规则？
                     (至少一条强匹配)
                          │
              ┌───────────┴───────────┐
              │ YES                   │ NO
              ▼                       ▼
    ┌──────────────────┐    ┌──────────────────┐
    │ 强匹配路径        │    │ 弱匹配路径        │
    │                  │    │                  │
    │ 选 strong 中     │    │ 选 4 条规则中     │
    │ score 最高者     │    │ score 最高者     │
    │                  │    │                  │
    │ 置信度 =          │    │ 置信度 =          │
    │ 0.75 + score×0.2 │    │ 基于 margin 计算  │
    │ (上限 0.95)      │    │ (范围 0.35~0.80) │
    └──────────────────┘    └──────────────────┘
              │                       │
              └───────────┬───────────┘
                          ▼
                  最终输出结果
```

### 7.2 置信度计算详解

**强匹配路径**（至少满足一种类型的全部强匹配条件）：

$$C_{\text{strong}} = \min(0.75 + s_{\text{best}} \times 0.2,\; 0.95)$$

置信度范围：**0.75 ~ 0.95**

**弱匹配路径**（无任何强匹配）：

$$C_{\text{weak}} = \max(0.35,\; \min(0.5 + m,\; 0.80))$$

其中 $m = s_{\text{best}} - s_{\text{second}}$（第一名与第二名的分差）

置信度范围：**0.35 ~ 0.80**

> **设计意图**：强匹配路径置信度更高，因为该类型的所有指纹特征都得到了充分验证；弱匹配路径依赖相对排名，不确定性更大。

### 7.3 决策伪代码

```python
rules = [
    ("corona",   corona_match,   corona_strong),
    ("surface",  surface_match,  surface_strong),
    ("internal", internal_match, internal_strong),
    ("floating", floating_match, floating_strong),
]

# 第一级：检查是否有强匹配
strong_matches = [(type, score) for type, score, is_strong in rules if is_strong]

if strong_matches:
    best_type = max(strong_matches, key=lambda x: x[1])[0]
    confidence = min(0.75 + best_score * 0.2, 0.95)
else:
    # 第二级：按分数排序选最优
    best_type = max(rules, key=lambda x: x[1])[0]
    margin = best_score - second_best_score
    confidence = max(0.35, min(0.5 + margin, 0.80))
```

## 8. 严重等级判定

根据放电信号的最大幅值和 P90 幅值，将危险程度划分为四个等级：

| 严重等级 | 英文标识 | 判定条件 | 含义 |
|:--------:|:--------:|----------|------|
| **critical** | 危急 | `max_amp > 5000 mV` 或 `P90 > 3000 mV` | 高幅值密集放电，需立即处理 |
| **warning** | 警告 | `max_amp > 2000 mV` 或 `P90 > 1000 mV` | 明显异常放电，需关注 |
| **attention** | 注意 | `max_amp > 500 mV` | 存在轻微异常迹象 |
| **normal** | 正常 | 其他情况 | 放电水平在正常范围内 |

> **注**：幅值单位为 mV（毫伏），具体阈值可根据实际设备灵敏度调整。

## 附录 C：工况自适应校准（设计建议）

当前分类器的所有阈值（quad13>0.50、symmetry>0.60 等）均为固定值。实际中传感器灵敏度、安装位置、背景噪声水平的差异会导致固定阈值的准确率波动。

### C.1 自动校准模式

在系统启动或用户触发校准时，采集一段已知无放电的基线数据，自动计算动态阈值：

```python
# 伪代码示意
def auto_calibrate(baseline_phases, baseline_amps):
    """
    根据基线数据计算自适应阈值
    baseline_phases: 无放电状态下的相位数组（纯噪声）
    baseline_amps: 对应幅值数组
    """
    noise_floor = np.percentile(baseline_amps, 95)  # 噪声底限
    _, _, H = np.histogram2d(baseline_amps, baseline_phases, ...)
    baseline_spread = calc_spread(H)  # 基线均匀度
    
    return {
        "noise_floor": noise_floor,
        # 阈值 = 基线值 × 安全余量
        "noise_reject_spread": max(0.80, baseline_spread * 0.9),
        "min_events": max(10, int(len(baseline_phases) * 0.01)),
    }
```

### C.2 建议工程实现

| 阶段 | 方案 | 复杂度 | 优点 |
|------|------|:------:|------|
| 短期 | 附录 B 参数表暴露更多可配置项 | 低 | 用户可手动调参 |
| 中期 | 自动校准模式（附录 C.1） | 中 | 一键适配现场 |
| 长期 | 基于历史分类结果的阈值反馈优化 | 高 | 持续自我优化 |
